# DocNest 示例文档

DocNest 是一个可嵌入任意 Node.js 项目的本地 Markdown 文档中心：项目负责提供自己的文档，DocNest 负责把这些文档变成可导航、可预览和可导出的文档站点。

你现在看到的 `docs/` 是 DocNest 仓库自带的体验项目。它既展示文档目录结构，也用真实内容说明 DocNest 适合解决什么问题、如何接入以及哪些能力可以按项目策略开启或限制。

## 三分钟开始体验

在 DocNest 仓库根目录执行：

```bash
npm install
npm run dev -- --no-open
```

浏览器打开终端输出的地址即可。默认读取当前目录的 `docs/`，从 `3000` 端口开始寻找空闲端口；修改任意 Markdown 后，已打开的页面会自动刷新。

## DocNest 能做什么

### 把项目文档变成一个真正的阅读界面

- 自动扫描 Markdown 文件和多层子目录，生成左侧目录树。
- 每个目录的 `README.md` 自动作为目录入口，排在同级文档之前，并显示“README/目录说明”标记。
- 根据 Markdown 标题生成本页导航、面包屑和当前文档高亮。
- 保留代码块、表格、引用、图片、附件和相对文档链接的阅读体验。

### 让图表和长文档更容易被理解

- 原生渲染 Mermaid 流程图、时序图等图表。
- 普通模式支持 Mermaid 大图查看、缩放、拖拽和 PNG/SVG/PDF 下载。
- 横向长图默认从可滚动的左边界开始，避免打开后看不到起点。
- 长文档 PDF 导出会按内容块寻找分页位置，尽量避免标题、表格和图表被截断。

### 让外观和发布策略由宿主项目决定

- 内置五套独立主题，主题风格与明暗模式可以分别选择和持久化。
- `site.title`、目录顺序、端口、监听地址、文档来源和授权策略均可配置。
- `restrictedMode` 统一控制受限阅读：开启后隐藏 PDF/打印、Mermaid 下载和大图查看，并显示固定的项目标题水印。
- 普通模式导出 PDF 时，可以仅对本次导出选择是否加水印并编辑水印文案，不修改配置。

### 保持本地优先、项目解耦

- 默认只启动本地服务，不绑定云厂商、远程发布或特定 CI/CD 平台。
- 文档仍属于宿主项目；除了本地 `docs/`，也可以通过存储适配器提供文档内容。
- 需要保护内部资料时，可启用极简单口令授权；不引入账号、角色和复杂身份系统。

## 推荐体验路径

1. 从[快速开始](./01-快速开始/README.md)了解安装、启动和最小配置。
2. 阅读[使用说明](./01-快速开始/使用说明.md)，按操作顺序体验目录、主题、图表和 PDF。
3. 打开[配置说明](./01-快速开始/配置说明.md)，查看宿主项目可调整的策略。
4. 进入[图表示例](./02-图表示例/README.md)，体验横向流程图和嵌套目录。
5. 查看[阅读体验](./03-阅读体验/README.md)，观察长文档常见元素的排版。
6. 最后查看[完整流程图](./示例流程图.md)，把启动、阅读、编辑和导出串起来。

## 示例目录结构

```text
docs/
├── README.md                 # 文档中心首页
├── 01-快速开始/
│   ├── README.md             # 子目录入口说明
│   ├── 使用说明.md
│   └── 配置说明.md
├── 02-图表示例/
│   ├── README.md
│   ├── 横向发布流程.md
│   └── 进阶/README.md        # 更深层的 README 入口
├── 03-阅读体验/README.md
└── 示例流程图.md
```

目录和 README 是结构演示；其余页面则围绕能力、亮点和使用方式组织，方便把示例直接替换成宿主项目自己的知识库。
