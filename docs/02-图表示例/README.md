# 图表示例

DocNest 不要求项目额外搭建图表服务。Markdown 中的 Mermaid 代码块会由文档中心在浏览器中直接渲染，适合架构图、流程图、时序图和状态机等技术内容。

## 这个目录展示的能力

- Mermaid 图表与普通 Markdown 内容混排。
- 横向长图默认保持左边界可达，打开大图后可以缩放和拖拽。
- 普通模式支持 PNG、SVG、PDF 下载。
- 受限模式只保留站内阅读，隐藏大图和下载入口。
- `进阶/README.md` 展示多层目录中的 README 仍然是入口文档。
