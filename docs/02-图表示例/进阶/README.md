# 图表进阶

这是第二层子目录中的 `README.md`。它验证 DocNest 可以在多层目录中持续提供一致的 README 特殊样式和目录跳转行为，而不需要额外维护目录索引文件。

## 这个页面验证什么

- 目录树的层级缩进和展开状态。
- 面包屑从根目录到当前子目录的路径。
- 当前目录 README 优先作为入口文档。
- 上级目录 README 与当前目录 README 都能通过相对链接访问。

## 建议用法

可以按业务领域继续拆分目录，例如：

```text
架构设计/
├── README.md
├── 服务边界.md
└── 数据流/
    ├── README.md
    └── 同步流程.md
```
