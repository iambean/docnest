# 配置说明

DocNest 的配置文件位于宿主项目根目录的 `docnest.config.mjs`。建议从仓库提供的 `docnest.config.example.mjs` 复制一份，再按项目需要修改。

## 最小配置

```js
import { defineConfig } from 'docnest/config'

export default defineConfig({
  docsDir: 'docs',
  site: {
    title: '我的项目文档',
  },
  restrictedMode: false,
})
```

## 常用配置

```js
export default defineConfig({
  docsDir: 'docs',
  site: {
    title: '我的项目文档',
    subtitle: '团队知识库',
    storageKeyPrefix: 'docnest:my-project',
  },
  navigation: {
    rootDirectoryOrder: ['架构设计', '开发规范'],
  },
  appearance: {
    defaultTheme: 'slate-modern',
    defaultMode: 'auto',
    enabledThemes: ['slate-modern', 'editorial-atlas', 'precision-index'],
  },
  server: {
    port: 3000,
    watch: true,
    openBrowser: true,
  },
})
```

- `docsDir`：文档根目录，可以指向项目自己的知识库目录。
- `site`：站点标题、副标题和浏览器存储键前缀；受限模式水印直接使用 `site.title`。
- `navigation.rootDirectoryOrder`：只调整根目录下的目录顺序，不影响子目录自然排序。
- `appearance`：设置默认主题和可用主题；主题风格与明暗模式是两个独立维度。
- `server`：设置监听地址、起始端口、Watch 和自动打开浏览器行为。

## 受限阅读模式

将 `restrictedMode` 改为 `true` 后，页面会固定显示 `site.title` 水印，同时隐藏 PDF/打印、Mermaid 下载和 Mermaid 大图查看入口，并禁止正文文字选择与复制。

普通模式下将其设为 `false`，即可恢复这些阅读和导出能力。导出 PDF 时可以在弹窗中选择是否添加水印，并临时编辑水印文案；默认文案为 `site.title`，不会写回配置。

## 单口令授权

如果文档只需要一道入口，可以启用极简单口令授权：

```js
export default defineConfig({
  auth: {
    enabled: true,
    passphrase: '请替换为项目自己的长口令',
    // 反向代理挂载在子路径时填写，例如 /documents；默认跳转到 /。
    redirectPrefix: '',
    stateFile: '.docnest/auth.json',
    localStorageKey: 'my-project:auth-passphrase',
    sessionTtlMinutes: 24 * 60,
  },
})
```

它没有账号、角色或权限层级。用户输入正确口令后，浏览器会保存可回填的口令，每次打开页面仍由后台重新校验。

如果 DocNest 由反向代理挂载在 `/documents/` 等子路径下，将 `auth.redirectPrefix` 配置为 `/documents`。这样登录页和口令登录后的跳转都会保留挂载前缀；不配置时保持默认跳转到 `/`。
