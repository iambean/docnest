# 快速开始

本页是一个子目录 `README.md`，也是 DocNest 约定的目录入口。它展示了“文档内容由项目提供，文档中心负责组织和呈现”的最小使用路径。

## 安装与启动

在宿主项目中安装：

```bash
npm install docnest
npx docnest serve
```

如果你正在运行本仓库源码，可以使用：

```bash
npm install
npm run dev -- --no-open
```

启动后，DocNest 会读取项目根目录的 `docs/`，默认绑定 `127.0.0.1`，从 `3000` 开始寻找空闲端口。`--docs-dir`、`--port`、`--host` 和 `--no-open` 可用于临时覆盖配置。

## 第一个文档

1. 在项目根目录创建 `docs/README.md`。
2. 写入 Markdown 标题、正文、代码块或 Mermaid 图表。
3. 启动 DocNest，左侧目录树会自动出现该文档。
4. 修改文件并保存，已打开的页面会通过 Watch 自动刷新。

## 这个 README 的特殊效果

- 左侧目录树中排在本目录其他文档之前，并带有 `README` 标记。
- 访问 `01-快速开始/` 目录时，会优先跳转到本页。
- 子目录可以继续嵌套，深层目录仍然遵循同样的 README 入口规则。
