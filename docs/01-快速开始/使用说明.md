# 使用说明

这份页面按“第一次打开文档中心后会做什么”的顺序，介绍 DocNest 的主要操作。

## 1. 浏览和定位文档

- 左侧目录树按目录层级展示 Markdown 文件。
- 点击目录可以展开或收起；当前文档所在的目录会自动展开。
- `README.md` 是目录入口，会被置顶并显示特殊标记。
- 标题较多时，正文左侧的“本页导航”可以快速跳转到章节。
- 面包屑显示当前文档所在路径，便于回到上级目录。

## 2. 切换主题

右上角主题选择器支持五套文档风格：

| 主题 | 适合场景 |
| --- | --- |
| Slate Modern | 通用项目文档，清晰克制 |
| Editorial Atlas | 长篇说明和技术出版物 |
| Precision Index | 高密度工程索引 |
| Archive Room | 方案归档和知识阅览 |
| Swiss Manual | 工程手册和操作规范 |

主题风格与浅色/深色/跟随系统模式分别保存，刷新页面不会丢失选择。

## 3. 阅读 Mermaid 图表

普通模式下，点击图表可以打开大图查看器：

- 缩小、放大或恢复默认缩放。
- 横向长图可以通过滚动条和拖拽查看完整内容。
- 可将图表下载为 PNG、SVG 或 PDF。

如果项目开启 `restrictedMode`，图表仍会正常渲染，但大图查看和下载入口会被移除。

## 4. 导出 PDF

普通模式下，文档页顶部提供打印和下载 PDF：

1. 点击“下载 PDF”。
2. 选择本次是否添加水印。
3. 需要时修改水印文案；默认文案来自 `site.title`。
4. 点击“确认下载”。

水印选择只影响这一次导出，不会改动 `docnest.config.mjs`。受限模式下不会显示 PDF 入口。

## 5. 编辑时实时刷新

开发阶段保持 Watch 开启即可：

```bash
npx docnest serve --watch
```

保存 Markdown 后，DocNest 会通过本地服务通知浏览器刷新页面；新增、删除和修改文档都会同步到目录树。
