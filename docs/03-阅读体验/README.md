# 阅读体验

DocNest 的重点不是把 Markdown 原样塞进一个页面，而是让项目文档更适合持续阅读、定位和交付。本页集中展示常见内容在文档中心中的组合方式。

## 章节导航

页面中的标题会自动生成“本页导航”。长文档可以按背景、方案、操作、风险和附录拆成清晰章节，读者不需要反复滚动寻找位置。

## 信息块

> 目录 README 是入口，不是特殊格式要求。只要文件名为 `README.md`，DocNest 就会自动识别，并将它置顶显示。

| 元素 | 在 DocNest 中的表现 | 适合内容 |
| --- | --- | --- |
| 标题 | 自动生成章节导航 | 方案、规范、操作手册 |
| 表格 | 保持 Markdown 结构 | 参数、字段、对比项 |
| 代码块 | 保留语法高亮 | 命令、配置、接口示例 |
| 引用 | 突出提示内容 | 注意事项、结论、风险 |

## 代码块

```bash
# 开发时启动本地文档中心
npx docnest serve --no-open

# 指定文档目录和起始端口
npx docnest serve --docs-dir docs --port 3000
```

## 适合沉淀的内容

- 架构设计、技术方案和 ADR。
- 开发规范、部署手册和故障排查记录。
- API、数据字典和跨团队协作说明。
- 需要 Mermaid 图表、附件和长文档 PDF 的项目资料。
